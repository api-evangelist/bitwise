# Bitwise

> Bitwise Asset Management is a crypto-focused investment manager offering index funds, ETFs, SMAs, and staking products. Its read-only market-data API exposes Bitwise index metadata, historical daily index values, index constituents, per-fund data (NAV, AUM, holdings), and ETF listings, authenticated with an API key in the Authorization header.

## APIs
- [Bitwise API developer portal](https://developers.bitwiseinvestments.com/): Postman-published reference for indexes, ETFs, and fund data. Base URL https://api.bitwiseinvestments.com. Request keys from api@bitwiseinvestments.com.
